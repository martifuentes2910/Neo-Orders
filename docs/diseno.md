# Diseño

## Paleta

- **Primario**: violeta `#7c3aed` (claro) / `#8b5cf6` (oscuro)
- **Acento 1**: fucsia `#d946ef` / `#e879f9`
- **Acento 2**: turquesa `#14b8a6` / `#2dd4bf`

## Temas

- **Claro**: fondo blanco, superficies `#f7f7f8`, texto `#0a0a0a`.
- **Oscuro**: fondo `#0b0b0d`, superficies `#1c1c20`, texto `#f4f4f5` (gris negro, no azulado).

## Estados de pedido

| Estado | Color |
|--------|-------|
| Pendiente | ámbar |
| En proceso | azul |
| Enviado | violeta |
| Entregado | verde |
| Cancelado | rojo |

## Iconografía

Se usan iconos SVG de `lucide-react`. No se utilizan emojis.

## Tipografía

Inter (con fallback a la pila del sistema). Tamaños: 12–24px.
